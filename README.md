# Beijing Air Quality Analytics Dashboard 🌤️

Proyek akhir analisis data ini bertujuan untuk mengunduh, membersihkan, menganalisis, serta menyajikan visualisasi interaktif dari dataset **Beijing Air Quality (PRSA Data 2013-2017)** guna menjawab pertanyaan bisnis terkait pola spasial dan temporal dari konsentrasi polutan $\text{PM}_{2.5}$.

---

## 🛠️ Setup Environment - Anaconda / Miniconda

```bash
conda create --name main-ds python=3.9 -y
conda activate main-ds
pip install -r requirements.txt
